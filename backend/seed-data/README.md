# seed-data

Import artifacts for the exercise catalogue (see `docs/03` — seed, not a runtime dependency).

## `wger-catalogue.json`

Generated by `MySelf.Tools.WgerImport`. A normalised, source-agnostic snapshot of the
[wger](https://wger.de) exercise catalogue (CC-BY-SA — attribution stored per exercise).

Regenerate (needs network):

```
dotnet run --project backend/MySelf.Tools.WgerImport -- fetch
```

Load into PostgreSQL (idempotent, no network — reads `ConnectionStrings__DefaultConnection` from `.env`):

```
dotnet run --project backend/MySelf.Tools.WgerImport -- import
```

## `tracking-mode-overrides.json`

Manual corrections to the auto-classified `DefaultTrackingMode`. Map a wger `uuid` to a
`TrackingMode` name; applied during `fetch`.

```json
{
  "0b1c...uuid": "BodyweightPlusWeight",
  "9f3a...uuid": "RepsOnly"
}
```
